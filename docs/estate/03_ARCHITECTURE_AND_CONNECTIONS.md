## Independent creative pipelines

1. **Images:** `image_asset_generator/manifest.json` / `canonical_version_catalog.json` → guarded `provider_renderer.py` or deliberately deterministic `generate_assets.py` → `validate_assets.py` → `create_preview.py` → `export_assets.py` / `export_spatial_handoff.py`. Current prompt lists are input plans. Canonical release contract is 213 identity slots. Existing Spatial WebP assets must be compared by exact path, byte and rights before any new purchase.
2. **3D Models:** `model_forge/launch-model-inventory.json`, `specs/` and `reference-resolution.json` → `forge.mjs` and `model-spend-client.mjs` → selected Meshy/Tripo/Rodin/Replicate Hunyuan candidate request/poll → actual bounded download and hashed embedded GLB → `validate-glb.mjs` and `glb-container.mjs` (reject missing geometry/texture sidecars) → Blender `clean-export.py` (scale/pivot/LOD0–2) → `render-review.py` and literal scene render → human visual approval → `verify-promotion.mjs` → Spatial consumer. Default `--dry-run` spends nothing. `model_forge/runs/` is intentionally untracked. External provider receipt alone cannot fill that Git gap.
3. **Original generic worlds:** `model_forge/generic-worlds/v1/build/` manufactures original procedural 3D geometry, UVs, PBR-style materials, collision/nav metadata and design-level LODs, validated by `qa/`. Version 1.0.2 archive is external, **not in Git**; a staging summary is not an executable asset import. All literal visual, mobile, XR and navigation acceptance remain separate.
4. **Factory Studio:** `assetfactory-studio/app/api/`, `lib/server/assetTypeCatalog.ts`, `assetRenderer.ts`, `assetProviderRuntime.ts`, `assetVideoProviderRuntime.ts`, `cloudAssetFactoryStore.ts`, `assetAuth.ts`, `assetQueue*.ts`. Deterministic local generator: SVG graphic, tiny glTF proof mesh, synthesized WAV, JSON bundle. Routes implement generate → materialize → fetch → publish → approve, with optional Firebase/Storage/Functions, production adapter, tenant guards, leases, spend, Stripe and retention interfaces. `docs/MULTIMODAL_ASSET_WIRING.md` documents the exact local mode. Real dedicated deployment and protected cross-tenant provider execution still require separate tests.
5. **Cinematics:** `film_foundry/finite_time/`, `launch-films/waiting-room/`, `manifests/film/`, `scripts/generate_*.py`; storyboard/shot/audio description/haptic/caption contracts → no-spend animatic → authorizations → provider/media render → private or public safe delivery. The finite-time 30-shot plan is deterministic proof with `finalRenderingAuthorized=false`, **not a final movie**.
6. **Captured reality/Home:** `model_forge/captured-reality/` typed receipt/QA; Home reference → actual source image retention and SHA → camera solve/SfM → Gaussian train → mesh proxy → PBR foreground → package → Spatial current visual route proof and owner Gold Master approval. `docs/home/HYBRID_HOME_GOLD_MASTER_AUTHORITY.md` explicitly separates `INTERPRETIVE` from truly recorded truth and requires visual and navigation proof.

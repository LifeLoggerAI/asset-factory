## Decision

UrAi Home uses a hybrid runtime:

`photoreal Gaussian/splat environment + real foreground meshes + collision/navmesh proxies + interactive GLBs + React/R3F runtime systems`

The existing `home-entry-chamber-v1.glb` remains valid reusable work, but is not the sole Gold Master visual authority. It may serve as fallback, collision/layout proxy, foreground source, proof fixture, or reference after inspection.

## Visual and behavioral ownership

| Responsibility | Authority |
|---|---|
| Scene lifecycle, camera, first-person movement, inputs | React/R3F |
| Photoreal environment shell, distant/mid-range context, atmospheric richness | Gaussian/splat layer |
| Walkable floors, stairs, railings, near-field structure and furniture | Conventional meshes |
| Collision, navmesh, safe boundaries and fall prevention | Invisible collision/navmesh geometry |
| Orb, Passport, interactive props, animated objects and transitions | Interactive GLBs + React/R3F state |
| Dynamic lighting, weather, atmosphere and personalization | React/R3F lighting/runtime |
| Audio, captions, TTS, reduced motion/stimulation and accessibility | React/UI/accessibility systems |
| Quality selection, streaming, LOD and no-WebGL fallback | Runtime quality/fallback owner |
| Source, license, provider, truth class, hash and transformation history | Asset Factory provenance authority |

No Gaussian layer owns collision or semantic interaction. No baked environment owns the living Orb, dynamic weather, accessibility, or transitions.

## Truth classes

The purpose-designed/generated Home sanctuary is **INTERPRETIVE**.

A personally recorded and reconstructed place is **RECORDED SOURCE TRUTH / SPATIALLY RECONSTRUCTABLE**. These classes must remain explicit and must not be mixed or relabeled.

## Canonical Home constraints

Home remains a sky-dominant, first-person, inhabited sanctuary with no hands/arms, warm natural materials, believable regional continuity, stone/timber/glass/textile detail, vegetation, living traces, work/purpose traces, and an interactive Orb. It must not read as a sci-fi corridor, portal temple, neon game world, low-poly blockout, or ceiling-dominant traversal space.
